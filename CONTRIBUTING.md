# Contributing to TokenScalpel

Thank you for contributing to **TokenScalpel**!

## Engineering Rules
1. **Zero-Bloat:** Keep core utilities dependency-free in pure Node.js.
2. **Evidence Over Intuition:** Every optimization or evaluation change must include reproducible numbers from `npm run bench` or `npm run eval`.
